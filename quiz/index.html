튜터 꺼짐

복습 문제 · 객관식

보기를 고르면 그 방법을 실제 데이터로 실행한 결과가 나옵니다. API 키 없이 풀 수 있습니다. 점은 난이도(2 ~ 5)입니다.

토의 과제

현업 문제와 데이터만 보고 어떻게 접근할지 정리합니다. 튜터와 이야기하려면 API 키가 필요하고, 키가 없으면 스스로 정리한 뒤 모범 접근을 펼쳐 봅니다.

실행 결과

튜터

본인 API 키로 대화합니다

튜터는 선택 기능입니다. 본인의 Anthropic API 키를 넣으면 고른 이유를 말로 설명하고, 빠뜨린 점을 짚어 받을 수 있습니다.

키가 없어도 객관식 풀이와 해설은 모두 볼 수 있습니다.

튜터 설정

튜터는 Anthropic의 Claude를 부릅니다. 대화 비용은 넣은 API 키의 계정에서 나갑니다.

  • 키는 이 브라우저에만 보관되고, Anthropic API(api.anthropic.com) 말고는 어디에도 보내지 않습니다. 기억하기를 끄면 창을 닫을 때 지워집니다.
  • 이 용도로만 쓰는 키를 새로 만들고, Anthropic Console에서 사용 한도를 걸어 두세요.
  • 회사 PC라면 외부 서비스에 키를 넣어도 되는지 사내 보안 규정을 먼저 확인하세요.
